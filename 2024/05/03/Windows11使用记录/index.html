Windows 功能

某些功能，Windows 默认没有开启，需要你进入 Windows 功能手动启用或关闭，重启系统生效。

如何进入启用或关闭 Windows 功能？

常规方式打开 Windows 功能：

  1. 进入控制面板，使用快捷键 win + r 键入 control，或者使用 powershell 键入 control。
  2. 定位到程序与功能。
  3. 进入选择开启或关闭 Windows 功能。

那么，问题来了，我们如何快速进入 Windows 功能模块呢？

答：使用命令 OptionalFeatures 形式。

powershell_OptionalFeatures

dwm高耗内存问题

正常状态：

如果你在使用 Intel 处理器（帯核心显卡，或者称为集成显卡），使用操作系统为 Windows 11 专业版 21H2，可能会存在 dwm 进程高耗内存问题。

dwm.exe（台式机窗口管理器）使用高于 27.20.100.8587 的驱动程序生成内存泄漏

Windows 11 程序 dwm 高耗内存问题：解决方案

总结 描述 27.20.100.8587 以上的驱动程序导致 dwm.exe（台式机 Windows 管理器）产生内存泄露的问题。

说明 dwm.exe 。使用第六代智能英特尔处理器通过第十代智能®英特尔®处理器产生内存泄露。dwm.exe 内存的使用开始较低（约 30MB），随着时间的推移积累，并可能导致系统崩溃。

解决方法 安装英特尔®显卡 – Windows* DCH 驱动程序 30.0.101.1191 或更新版本来修复此问题。 https://www.intel.com/content/www/us/en/download/19344/691496/intel-graphics-windows-dch-drivers.html? 如果 Windows Update 分发了另一个驱动程序，则在安装驱动程序 30.0.101.1191（包括 dwm.exe 泄漏的修复程序）之前应执行清洁的驱动程序安装。
