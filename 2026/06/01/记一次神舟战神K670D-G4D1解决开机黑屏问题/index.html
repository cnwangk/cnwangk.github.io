    联想 v370 重装系统 Windows10 Enterprise LTSC 2021

记一次神舟战神K670D-G4D1 解决开机黑屏问题、换U与重装系统 Windows10 Enterprise LTSC 2021 21H2

发表于 2026-06-01 更新于 2026-06-30 分类于 3C数码一起撩 阅读次数： 本文字数： 2.2k 阅读时长 ≈ 8 分钟

我给自己埋了一个坑，CPU 硅脂涂抹稍微厚了一点点。

自己用的时候完全没问题，2023 年更换新笔电，测试没问题才把旧笔电寄回家备用。由于旧笔电三年多没有开过机，结果某天开机风扇在转吹出热风，电源指示灯亮但屏幕黑屏。

我寻思，难道 CPU 有问题？硅脂过厚或者没压好。

清理硅脂

原来的硅脂薄薄的一层，后来我更换的硅脂比购买的笔记本电脑原始硅脂厚了至少 2~3 倍。

忘记保留更换硅脂后的图片，使用2023 年左右拍的图片作为说明（彼时硅脂快干成粉末状）。

G4560，使用五年，第一次拆机更换硅脂，干成粉末了。

旧笔电（笔记本电脑）又放家里三年没用过，开机屏幕不亮。我排查过固态硬盘、内存条，均没问题。猜测，有可能 CPU 过热导致黑屏。于是，拆机刮掉一部分硅脂，轻松秒杀。

G4560，用的时间不久（很少拆机），成色显得很新。

拆机的时候，CPU 散热模组黏的很紧。起初，我还纳闷散热效果不佳，是不是买的硅脂太垃圾（7.5 元/1g），或者涂少了。有一说一，笔电使用桌面端 U，模具不行，散热够呛。结果发现，硅脂不是涂的越厚越好，反而薄薄一层均匀导热即可。D 面进风，两侧出风，通过散热模组热管将热量导出，最后由风扇向外排。

最初拆下来的 G4560 最多作为备用，寻思着，还得换 U。

更换 CPU

以前购买的 i5-8400 散片，刷完 BIOS 以及屏蔽针脚，依旧有点小毛病，散热压的有点勉强。由于后来没怎么使用，顺手把 i5-8400 散片出掉。如果当时换的是 i3-8100，只需刷 BIOS，无需屏蔽针脚。使用 i5-8400，需要 BIOS 以及屏蔽针脚，即便不屏蔽针脚，也影响不大。屏蔽针脚，只为不影响回血。

后来，我又重新更换为 i5-7500，二手大概 120 元左右，成色好一点的大概在 150 元左右。

拆下来的 G4560，看了一眼小黄鱼/某宝/拼夕夕二手只值 15 元。索性被我当钥匙扣使用，哈哈。如果手里有合适的闲置配件，其实可以当做 NAS 使用。当然，还可以亮机用。再怎么拉跨，G4560 也有一个能用的核显。

风险与性价比相辅相成。

如果你有关注过贴吧准系统吧，会发现有不少 DIY 用户通过刷 BIOS 以及屏蔽针脚，更换更高规格的 CPU，性价比拉满。比如 i3-8350K 需要刷BIOS，以及 i7-8700 ES（qn8h）需要刷 BIOS 以及屏蔽针脚。如果刷 BIOS ，注意仔细阅读原作者的说明文档，避免刷错，导致变砖。

目前，不建议折腾准系统，性价比不高，也没太大的意义。

更换 CPU，再次刷回神船（蓝天）原版 BIOS，发现 CPU 睿频不正常。

于是乎，开始排查问题，考虑到有可能受限于 BIOS，存在 CPU 锁倍频问题。

解锁 CPU 倍频

关于 CPU 锁倍频的问题。

如果遇到 CPU 单核与全核睿频上不去（锁倍频），大概率原始 BIOS 与 EC 版本受限，导致频率被锁。Intel CPU 可以借助 ThrottleStop 解锁突破限制。

如果你正在使用 ThrottleStop ，需要了解一些风险。

如下所示，通过 ThrottleStop 解锁突破睿频限制。

使用 FurMark CPU burner 测试 CPU 单核。

使用 Prime95 测试CPU多核。

至此，我心中的部分疑惑也得到解除。

值得注意的是，ThrottleStop 有一定的局限性，目前好像只支持 iU（Intel CPU）。

关于 ThrottleStop ，我截取了几张图，感兴趣可以前往 [1]ThrottleStop 官网了解详细用法。

ThrottleStop Turbo FIVR Control ，

ThrottleStop Turbo Limits，

ThrottleStop9.7 & TS Bench，

比如神舟战神K670D-G4D1，初始 BIOS 版本 1.05.08TSZ，EC 版本 1.05.07 。 不管你使用哪种工具检测，CPU 最大倍频锁死在 34 ~ 35 之间。我尝试使用过 [2]CPU-Z、[3]Prime95、[4]FurMark 以及 [5]AIDA64 等等工具狠狠的宠幸 CPU。

使用 i5-7500，我打算用来安装 Windows7，Windows10 Enterprise LTSC 2021 仅仅用于体验。

重装系统 Windows10 Enterprise LTSC 2021 21H2

原系统密码不记得了，懒得折腾。顺带重装 Windows10 Enterprise LTSC 2021 21H2，开机内存占用比 Windows11 少 14% 左右，巴适得很。

用的还挺顺手。由于 Microsoft Windows 官方精简了许多组件，开机占用内存确实很少，大概在 1.2GB 左右。

Intel 7代 U 旧版本核显驱动 21.20.16.4550，屏幕亮度可以正常调节。值得注意的是，牙膏厂（Intel）7 代核显驱动某一个版本（31.x，不记得具体版本，应该不是最新版本）有概率出现屏幕亮度无法调节的问题，也有可能是我记错了。。

我又尝试访问 Intel 官网并安装 Intel 7代 U 最新的核显驱动 31.0.101.2141，屏幕亮度无法调节的问题又解决了。

如果你和我一样安装并使用 Windows10 Enterprise LTSC 2021 21H2。值得注意的是，初始版本有一个小 bug，导致老款 CPU 100% 占用（新款 CPU 没有试过，尚不知道会出现什么 bug），功耗很高。可以手动下载安装补丁包

Microsoft.VCLibs.140.00_14.0.30704.0_x64__8wekyb3d8bbwe.Appx 解决此问题。

i5-7500 + GTX 1050，轻度办公娱乐，完全没问题。

个人习惯使用 PE 工具，简单省事。主要使用微PE 2.x，简洁无广子。当然，你也可以考虑使用 rufus 、ventoy 或者 iventoy。

如果你考虑使用 Windows10 1809 ，此版本存在一个 bug，

重装系统，进入系统引导界面选择地理位置存在卡死问题，使用输入法也会出现卡死问题。

解决方法，使用快捷键 shift + f10 调出 cmd 命令窗口，输入命令 taskmgr 进入任务管理器，寻找到微软拼音输入法应用程序进程名[6]Microsoft IME，结束即可。

唉，我居然忘记了 Windows10 1809 还存在这样一个 bug。

更换 cmos 电池

卸下笔电电池，再次拆机。力大出奇迹，固定笔电主板 cmos CR2032 纽扣电池塑料卡扣被我掰断了一个小角。

原本很简单的一个操作，只需要往后推（或者往里挤）就可以轻松取下 cmos 电池。结果，我的麒麟指发作。好在缺一个角，不影响固定。

重新安装 cmos CR2032 纽扣电池，再次轻松秒杀。原系统密码不记得了，懒得折腾。

开机，看到 Windows 系统提示

The CMOS battery is bad or was recently replaced.(If you cont inue to see this message, consult the system user ‘s guide for more information.)
Press Enter（OK）

，难道 CR2032 纽扣电池寄了或者没电？8 年多，也该没电了。索性购买新电池，直接更换。

拆开后盖，更换 cmos CR2032 纽扣电池，Windows 系统再次提示

The CMOS battery is bad or was recently replaced.(If you cont inue to see this message, consult the system user ‘s guide for more information.)
Press Enter（OK）

，根据提示，按回车键（Enter），重启之后正常进入系统。再次测试重启，系统正常。

我那颗独显，8 年没有更换过硅脂。也不是我想更换硅脂，主要我拿那两颗滑丝的固定螺丝没办法。其实，主要玩跑跑卡丁车，GPU 没啥压力，哈哈。

啊，我还需要给 NVIDIA GTX1050 4G laptop 显卡（GPU） 更换硅脂。

吐槽：神船笔电出厂，显卡（GPU）散热模组有两颗银白色固定螺丝滑丝。我也纳闷，滑丝的两颗螺丝该怎么拧下来，无语。。

原本 PH00 螺丝刀头即可正常拧下螺丝。但是，滑丝的螺丝不得行。我挨个尝试使用 PH00/PH0/Y1/PH1 四种型号，结果 Y1 刚好可以拧下滑丝的螺丝。

通过更换好几种型号的螺丝刀头，费了老大的劲，终于把滑丝的两颗螺丝成功拧下来。

对于不熟悉的模具，最好参考同类（同型号）产品拆机视频。

拆机需谨慎，力大有风险。
