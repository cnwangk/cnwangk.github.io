驾驶证到期了怎么换证

发表于 2024-03-19 更新于 2024-05-09 分类于 生活百科 本文字数： 2.3k 阅读时长 ≈ 8 分钟

驾驶证期满换证流程（异地）。

前往指定医院，完成体检，医院会上传提交体检报告到车管所数据服务中心。发票和纸质体检报告做为凭据自行保留哟。

异地办理的驾驶证，需要在交管12123 APP 选择迁移现居住地，提交近期 1 寸白底照片。

问：驾驶人期满换证需要经历哪些过程？

答：五个阶段。

如下所示：

  1. 提交申请阶段。
  2. 受理阶段。
  3. 制证阶段。
  4. 邮件交寄中阶段。
  5. 办理完成阶段。

问：正常办理驾驶人期满换证需要多久？

答：一般来说，当天完成体检，第二天可以收到受理办证信息。至于多久可以到手，取决于你是自行前往还是邮寄到手。以本人为例，当天体检后提交迁移申请，第三天下午收到快递（重庆渝中区），效率挺高的。

问：办理驾驶人期满换证需要花费多少钱？

答：根据各地体检收费标准而定。例如，我个人花费 70 元。消费组成，体检费用 50 元，驾驶证工本费 10 元，邮政快递费用 10 元。

Windows平台安装docker指定安装路径

发表于 2024-03-13 分类于 开发运维 本文字数： 1.4k 阅读时长 ≈ 5 分钟

演示使用 docker 版本：4.27.2

操作系统版本：Windows 11 家庭中文版 23H2 22631.3296

Windows 平台使用 PowerShell 7.2.5 安装 Docker Desktop on Windows，指定安装路径，比如 install --installation-dir=D:\software\Docker。如果你下载完，双击安装，默认安装路径为C:\Program Files\Docker\Docker。

如果遇到 Start-Process: A positional parameter cannot be found that accepts argument '--installation-dir=D:\software\Docker'.。

请尝试使用 Start-Process '.\Docker Desktop Installer.exe' 'install --installation-dir=D:\software\Docker'

做一个简单说明，在 Powershell 中使用某些命令指定参数，可能需要使用单引号或者双引号将指定参数拼接包裹起来，让系统将该命令识别为一个整体。

友情提醒：我这边安装测试环境默认采用 WSL2，你也可以使用 Hyper-V。
